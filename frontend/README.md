# Persistent Memory Tutor Frontend

React/Vite frontend for the Memory Tutor full-stack MVP.

## Setup

```bash
cd frontend
npm install
```

Optional `.env`:

```bash
VITE_API_URL=http://127.0.0.1:8001
```

## Run

```bash
npm run dev
```

Open:

```text
http://127.0.0.1:5173
```

## Build

```bash
npm run build
```

## Pages

- `/login`
- `/register`
- `/dashboard`
- `/chat`
- `/chat/:sessionId`
- `/memory`
- `/profile`
- `/progress`
- `/evaluation`
